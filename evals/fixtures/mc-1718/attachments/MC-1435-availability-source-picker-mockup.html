MC-1435 availability source picker mockup

Same Manage sources button and SourcePickerDialog shell as genres, ratings, videos and images. The body is variation B: a filterable country list on the left, and that country's sources on the right, each listing its services as tiles. The data is the real INT response for Avatar.

This ticket covers the GET only, so the dialog is read-only and has no Use button. Saving is a follow-up ticket. Try the United States (two sources), Japan (FOD has no company key) and the Netherlands (Pathé and meJane have no logo).

This mockup shows intent. Where it differs from the ticket text or repo conventions, those win.

Settled decisions

  1. Read-only. This ticket renders the GET only. There's no domain.write and no Use button, and no POST, PUT or DELETE is sent. Saving goes to a follow-up ticket, most likely per country (country_id), to be confirmed against the API docs.
  2. "In use" comes from the server. For the chosen country, the source with the lowest priority is in use (null ranks last, then lowest id). DEFAULT_ORDER [1, 2, 5] isn't used, because it leaves out JustWatch (3), which wins in 80 countries for Avatar.
  3. Offer labels keep the source's wording. Buy, Rent, Subscription, Flat rate. Qualities: SD, HD, 4K, Canvas. Price ranges are formatted in each offer's own currency, and price 0 shows as "Included".
  4. Repeated offers. Tiles merge exact duplicates. "Show every offer" lists each one once, with "sent N times".
  5. ProviderLogo. Every logo uses one frame size. Square art (JustWatch 100×100) fills the frame. Any other shape (GraceNote 4:3 wordmarks) is shown whole on --logo-plate, a new approved theme token that stays light in dark mode. No logo, or a failed load, shows initials.
  6. Default country. US when present, otherwise the first country with more than one source, otherwise the first alphabetically. The list groups "More than one source" first.
